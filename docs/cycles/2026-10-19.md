## Found, not fixed
- The player's cancel policy (`booking_unchanged`) and the coach's booking policy do not pin `recurring_id`, so a player cancelling could re-point a lesson's link if they knew a run's id. The ids cannot be guessed and End's query also filters on the player or the group; closing it means changing `booking_unchanged`'s signature, its policy and two function lists.
- An edit moves no lesson, because a move tells nobody yet (`trg_bookings_notify` acts only on a status change). The edit says so; moving them with a notice is on Next.
- A group's run tells nobody when it is ended: the trigger returns for a group booking. The End sheet does not promise it will.
- Ending a long run sends one notice per lesson to the player and to each of a junior's adults, as booking it did.
- `supabase/test/run.sh`: this clone is shallow, so the old-schema and guardian → family upgrade paths do not run here (`git fetch --unshallow`); they now say NOT RUN instead of nothing.
